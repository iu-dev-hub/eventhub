# Rehberler

Bu klasör, projede **nasıl çalışacağımızı** anlatan rehberleri içerir.

## Herkes okur

| Rehber | İçerik |
|---|---|
| [soft-vibe-coding.md](soft-vibe-coding.md) | Yapay zekâ ile sorumlu kod geliştirme: kurallar, istem şablonları, YZ'nin sık hataları |
| [pull-requests.md](pull-requests.md) | Dal, commit, PR açma, kod incelemesi, birleştirme çatışması çözme |
| [communication.md](communication.md) | Hangi bilgi nereye yazılır, iyi soru, geri bildirim, ekip anlaşması |

## Rolünüzün rehberi

| Rol | Rehber |
|---|---|
| Product Owner | [product-owner.md](product-owner.md): Müşteriyle çalışma, backlog, kabul kriterleri, kabul/red |
| Scrum Master | [scrum-master.md](scrum-master.md): Toplantılar, retrospektif, Scrum of Scrums, engeller, metrikler |
| Back | [backend-developer.md](backend-developer.md): İş kuralları, veritabanı, arayüz sözleşmesi, testler |
| Front | [frontend-developer.md](frontend-developer.md): Şablonlar, formlar, mesajlar, erişilebilirlik |
| Testçi | [qa-engineer.md](qa-engineer.md): Test yaklaşımı, teknikler, Playwright, keşif testi, hata raporu |

**Rol değiştiğinde** (Hafta 5, 9 ve 13) yeni rolünüzün rehberini okuyun ve eski rolünüzün
sahibine devir notu yazın.
